
# ProjectShield AI

### Intelligent Project Monitoring and Risk Prediction Platform

## Overview
ProjectShield AI is an intelligent platform designed to
monitor projects, analyze their progress, identify
potential risks, and predict possible delays.

## Objectives
- Monitor project progress.
- Predict possible project delays.
- Identify potential cost overruns.
- Detect project risks.
- Generate intelligent alerts.
- Visualize project performance.

## Technologies
- Python
- Machine Learning
- Pandas
- Scikit-learn
- Streamlit
- SQL

Currently under development.
